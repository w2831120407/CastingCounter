# 铸件计数器 (Casting Counter)

一款专为铸件生产车间设计的计数与效率统计安卓应用。

## 功能特点

### 📊 任务管理
- 设置今日任务数量（件）
- 设置每箱装件数，自动计算所需箱数
- 实时显示完成进度

### 🔢 快捷计数
- **+5** 和 **+10** 快捷按钮
- 支持手动输入任意数量添加
- **微信风格语音识别**：按住说话，说出"加XX件"或"加XX"自动添加
  - 基于 Vosk 离线语音识别引擎
  - 完全离线运行，无需联网，保护隐私
  - 实时音量波形动画
  - 支持上滑取消

### ⏰ 工时统计
- 设置上班时间和下班时间（24小时制）
- 支持夜班（+1天）模式
- 实时计算每小时产量

### 📈 数据分析
- 实时折线图展示产量趋势
- 推算预计完成时间
- 计算预计总耗时

### 💾 数据持久化
- 自动保存设置和进度
- 支持一键重置今日数据

## 技术栈

- Kotlin
- Android SDK 34
- ViewModel + LiveData
- MPAndroidChart (折线图)
- **Vosk 离线语音识别** (中文识别，完全离线)
- Kotlin Coroutines
- SharedPreferences (数据存储)
- GitHub Actions (CI/CD)

## 语音识别说明

应用使用 **Vosk 离线语音识别引擎**，不依赖 Google 服务，在国内设备上也能正常使用。

### 首次使用
1. 首次打开应用会提示下载语音模型（约30MB）
2. 点击"下载模型"按钮开始下载
3. 下载完成后即可使用语音识别功能

### 使用方式
- **按住说话**：按住语音按钮开始录音
- **松开结束**：松开按钮自动识别并添加件数
- **上滑取消**：按住状态下向上滑动可取消识别
- 支持的语音指令："加5件"、"加10"、"增加20件"、"再加15"等

## 构建

### 使用 Gradle 构建
```bash
./gradlew assembleDebug    # 构建 Debug 版本
./gradlew assembleRelease  # 构建 Release 版本
```

### GitHub Actions
项目配置了 GitHub Actions 自动构建，每次 push 到 main 分支都会自动构建 APK 并上传为 Artifact。
